Interaction notes

Push to talk. Hold Space (when no text field has focus) or press and hold the mic. Release to stop. A 2 second ring counts down with Cancel and Send now.

Voice can't approve. Saying “allow” opens the approval card. A click is always needed for risky actions.

Checkpoints. Instructions to busy Claude Code agents wait in amber until the current step ends, then the agent replies in a bubble.

Queries never interrupt. Answers come from the event log, show which events they used, and the agent keeps working.

Walking. Agents walk between rooms when their state changes: cabinets to read, server room to run things, library to browse, pantry when idle.

Subagents. A lead goes to the meeting room, sparkles appear, and the helper pops in at the closest free desk.

Time estimates. Each agent shows "~4m" on its tag and a full estimate in the panel, based on its own progress and pace.

Auto approve. The shield button in the office bar approves low risk actions for every agent, or everything after an extra confirmation. An amber banner stays on the floor while it is on.

Team offices. Subagents sit in a dashed office drawn around their lead. Open it from the agent panel and the camera zooms in on that team.

Model from settings. New agents use the default in Settings. Subagents use whatever their lead's agent settings say.

Envelopes. Handoffs, instructions and approvals fly across the floor as envelopes in their decision colour.

Conversations. When agents talk, a dashed curve joins them on the floor, an envelope flies across and the sender's bubble shows the message. The Conversations page keeps every thread.

Dispatcher. With no agent selected, Send to says Auto dispatch. A line under the command bar names the agent it will pick and why, and updates as you type.

Projects from a brief. New project opens a chat. Type or hold the mic, the planner proposes a lead and subagents, you untick or refine, then Start project. The lead walks in and brings its subagents.

Start Claude Code. Pick Claude Code in Start agent. The exact command is shown before it runs, and the session walks in on its own through the hook.

Project setup. New project works like a project chat: attach files with + or by dropping them, attach a repository by folder or Git URL, and keep instructions beside the chat. A file called CLAUDE.md, AGENTS.md or similar becomes the instructions. Plan first makes the lead post its plan on the notice board before anyone starts.

Working folders. Every folder field has Browse… to pick a folder on this computer, accepts typed or pasted paths (file:// links and quoted paths are cleaned up), suggests recent folders, and explains a path that won't work.

Time estimates. Name tags show minutes left. The panel adds the finish time, a likely range and, for leads, when the whole team should be done. The header shows when everything in view should finish, and the New project plan estimates the project before it starts.

Filters. Non matching agents fade to 20% and lose their tags, so the room stays readable.
